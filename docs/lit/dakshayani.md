# Literature Review — Dakshayani

| Paper Title & Year | Method / Architecture | Dataset Used | Key Result | Relevance to Our Project |
| :--- | :--- | :--- | :--- | :--- |
| Araci (2019), "FinBERT: Financial Sentiment Analysis with Pre-trained Language Models" | Fine-tunes BERT on domain-specific financial text to create FinBERT, a language model specialized for financial sentiment classification. | Two financial sentiment analysis benchmark datasets used to evaluate sentiment classification performance. | Reports improvement over prior state-of-the-art machine learning methods on every metric measured, even with a smaller training set and only partial fine-tuning. | This is the foundational paper behind the FinBERT model we use directly to score news headlines in src/sentiment/sentiment_analysis.py. It justifies why a domain-adapted language model outperforms general-purpose sentiment tools for financial text. |
| Jiang and Zeng (2023), "Financial sentiment analysis using FinBERT with application in predicting stock movement" | Combines FinBERT-derived sentiment scores with an LSTM network to forecast market trends; compares this against standard BERT, a standalone LSTM, and a traditional ARIMA model. | A dataset of stock market news headlines used to generate sentiment features for the prediction task. | Finds that adding FinBERT-based sentiment analysis meaningfully improves the model's ability to anticipate market fluctuations compared to the baseline approaches. | This paper's architecture is the direct template for our own FinBERT-LSTM model: extracting sentiment with FinBERT and feeding it into an LSTM alongside price data. It supports our planned price-only vs. price+sentiment ablation. |
