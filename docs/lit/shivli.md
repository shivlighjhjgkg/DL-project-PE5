# Literature Review — Shivli

| Paper Title & Year | Method / Architecture | Dataset Used | Key Result | Relevance to Our Project |
| :--- | :--- | :--- | :--- | :--- |
| *Deep learning with long short-term memory networks for financial market predictions (Fischer & Krauss, 2018)* | Plain LSTM trained on rolling windows of daily returns, benchmarked against random forest, a deep MLP, and logistic regression, then turned into a long/short trading strategy. | Daily constituent-level price data for the S&P 500, 1992-2015. | LSTM beat all baselines on directional accuracy and strategy return, but the edge shrank steadily through the sample as the pattern got arbitraged away by the market — a warning that backtested outperformance can decay over time. | Justifies using a plain LSTM as our sequential baseline (my task) and is a direct precedent for evaluating models on out-of-sample, chronologically later data rather than a random split. |
| *A deep learning framework for financial time series using stacked autoencoders and long-short term memory (Bao, Yue & Rao, 2017)* | Three-stage pipeline (WSAEs-LSTM): wavelet transform to denoise the price series, stacked autoencoders to learn compressed features, then an LSTM for the final forecast. | Daily data for six stock indices (e.g. S&P 500, HSI, DJIA, N225). | The full WSAEs-LSTM pipeline outperformed a plain LSTM and an RNN baseline on both prediction error and simulated trading return, showing that denoising/feature-extraction stages before the LSTM matter. | Motivates checking whether our FinBERT sentiment scores act as a similar "denoised feature" input, and supports keeping preprocessing (scaling, alignment) separate from the sequence model. |
| *Stock market's price movement prediction with LSTM neural networks (Nelson, Pereira & de Oliveira, 2017)* | LSTM fed technical indicators (moving averages, momentum, etc.) computed from OHLCV data, trained to predict next-step up/down direction rather than the raw price. | Minute-level data for stocks on the Brazilian Ibovespa index. | LSTM reached ~55-56% directional accuracy, beating a random forest and an MLP baseline on the same features, though the margin over simpler models was modest. | Supports our choice to report directional accuracy (not just MAE/RMSE) as a shared evaluation metric, and confirms that even a fairly standard LSTM is a legitimate, defensible baseline rather than something we should over-engineer. |
